# חק לישראל · הלימוד היומי

אפליקציית PWA ללימוד היומי לפי סדר חק לישראל, נוסח הספרדים.

- חלוקה לפי פרשת השבוע ויום בשבוע (א עד ו, וגם ליל שישי), מחושבת לכל תאריך בעתיד עם Hebcal (לוח ארץ ישראל)
- גרסה מקוצרת: תורה, משנה, גמרא והלכה פסוקה. גרסה מלאה: כל שמונת הסדרים, בשישי גם הפטרה
- פרשיות מחוברות מוצגות יחד, שבועות של חג מפנים לפרשה הבאה
- יומן: מה למדנו בכל יום, רצף, סימון סדרים שנלמדו
- במקביל: תהילים לפי יום בחודש, דף יומי, משנה יומית, רמב"ם יומי, הלכה יומית, תניא, 929 (דרך API של ספריא)
- עובד אופליין אחרי טעינה, עם כפתור להורדת כל השנה

## מבנה
- `index.html` האפליקציה
- `data/index.json` רשימת הפרשות, `data/<parasha>.json` הלימוד לכל יום (נבנה מדפי המקורות חק לישראל בספריא)
- `vendor/hebcal.min.js` חישוב תאריך עברי ופרשה
